# 邓健俊 | 个人作品集

这是一个用于课程实验（lab04）的个人作品集网站，展示个人介绍、项目作品与联系方式。

## 技术栈

- 原生 HTML、CSS、JavaScript，不依赖任何前端框架与第三方 UI 组件库
- 页面布局使用 CSS Grid 与 Flexbox，兼容桌面端和移动端

## 页面风格

网站采用 P5R（女神异闻录5 皇家版）风格的漫画 UI 设计：黑、红、白高对比配色，倾斜色块、硬边描边、速度线与角标编号等漫画元素贯穿全站。

## 页面内容

- **个人介绍**：姓名、方向标签与简介
- **项目作品**：由 JavaScript 数据渲染的项目卡片列表，包含项目描述、分类、日期与技术栈，滚动进入视口时有入场动画
- **关于我**：技能方向列表
- **联系方式**：邮箱等联系信息
- 左侧信息面板中的导航会随页面滚动自动高亮当前所在板块

## 主题切换（本次实验新增）

- 页面右上角提供深色 / 浅色主题切换按钮
- 深色主题为黑、红、白高对比风格；浅色主题以浅米白、浅灰为主背景，保留黑色描边与红色强调，仍保持漫画 UI 风格
- 用户选择的主题通过 `localStorage`（键名 `portfolio-theme`）保存，刷新或下次打开页面时自动恢复

## 目录结构


## 本地运行

方式一（推荐）：使用 VS Code 的 **Live Server** 插件

1. 在 VS Code 中打开本项目文件夹
2. 右键 `index.html`，选择 **Open with Live Server**
3. 浏览器会自动打开页面

方式二：使用 Python 内置服务器

```bash
cd lab04
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

方式三：直接双击 `index.html` 在浏览器中打开（主题切换等全部功能均可正常使用）。
